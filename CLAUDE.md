# Countries & Capitals: notes for Claude

Student project (owner is a beginner, speaks German). UI in English or German (`src/i18n.ts`: all texts, `useT()`/`useLang()`, saved in localStorage `country-capitals:lang`, first visit follows the browser language). German data per country in `countries.json` → `de` (capitals from Wikidata labels, government from Wikidata P122 or `overrides.json` → `governmentDe`, summary from de.wikipedia, languages/currencies via Intl.DisplayNames). Capital answers accept English and German names. Flashcard web app: learn all 198 countries and their capitals, Anki-style. Read README.md first for architecture, data sources, continent decisions and deploy steps.

## Facts worth knowing
- Run: Desktop file `Countries-and-Capitals.command` (symlink to `start-app.command`: builds, serves `vite preview` on http://localhost:4173, opens the browser). Dev: `npm run dev`. Tests: `npm test` (vitest). `npm run build` also runs the data completeness check.
- Stack: Vite + TypeScript + React, d3-geo/d3-zoom map, vite-plugin-pwa, Inter font bundled. No backend; progress lives in the browser's localStorage (key `country-capitals:v1`), export/import in Settings.
- Data: `data/countries.json` is generated (`npm run data:fetch`); manual fixes only in `data/overrides.json`; country list in `data/config.ts`.
- Scheduler: own Anki-style SM-2 in `src/progress/scheduler.ts`; queue + daily limits in `src/progress/store.ts`. New cards per day default = 250 (no limit: play whole continent).
- Design: clean Apple/BCG-like look, tokens in `src/index.css`. (An earlier "Iron Man HUD" design was replaced on purpose.)
- Study screen: map fills the page (`WorldMap` with `fill` + `reserve`), card floats on the right, the asked country is always highlighted; Oceania wraps the Pacific strip west of the date line.
- Two versions: `useDevice()` in `src/device.ts` = 'desktop' (fine pointer + width ≥ 1000) or 'mobile' (touch or narrow); also `<html data-device>` for CSS. Mobile: bottom `.tabbar` (not while studying; CSS var `--tabbar` = its height, fixed stages end above it), home = `.m-home` (edge-to-edge `.m-map`, figure tiles, swipe row of continents, `.m-start` floating button on phones). The home blocks (figures, mapContent, continentCards, mission) are shared JSX in App.tsx, arranged per device. Mobile CSS at the end of App.css.
- Home layout (desktop): fills one screen edge to edge (`--gutter`), slim hero strip, grid: map (`WorldMap fill`, takes all remaining height) | side panel of the same height (mission absolutely positioned, scrolls), continents in a row of 6 at the bottom (App.css "home layout"). Desktop root font size scales with the screen width (index.css), so prefer rem over px for sizes. The owner wants it sleek (Apple/BCG) with the big wide map.
- Satellite view: `src/map/mapStyle.ts` (`useMapStyle`, localStorage `country-capitals:mapstyle`), toggle = 🛰️ button in `.zoom-btns`. `public/satellite.jpg` is pre-projected by `npm run data:satellite` (NASA Blue Marble July, jpeg-js) using `src/map/projection.ts` (must stay the same as the map's projection, or the photo no longer matches the borders). CSS `.world-map.sat ...` in App.css.
- Sharp satellite: Esri World Imagery tiles (`src/map/satTiles.ts`, credit `.sat-credit` must stay visible). Globe: `globeTileEngineUrl`. Flat map: `satDetail.ts` reprojects the visible area into the Natural Earth projection after each zoom end (`scheduleDetail` in FlatMap), only when zoomed past the static picture's resolution.
- 3D globe: map style 'globe' (cycle flat → satellite → globe via `StyleButton` in WorldMap.tsx). Only maps with prop `globe` (home, StudyView) render `GlobeMap.tsx` (globe.gl/three.js, lazy chunk, excluded from PWA precache); others treat 'globe' as satellite. Texture `public/earth.jpg` also made by `npm run data:satellite`. Camera: `continentView`/`countryView`, `globeOffset` keeps it clear of the floating card (`reserve`). Cities = `htmlElementsData` (`.g-city`).
- Cities: `data/cities.json` from `npm run data:cities` (Natural Earth populated places, ≤5 per country, capital flagged), `src/data/cities.ts`. `WorldMap` props `cities` (dots + names, overlapping names hidden) and `zoomTo` (zoom in on a country; StudyView uses both after a right answer, MapQuiz only `cities`). Listed in `CountryFacts`.
- Tabs in the nav: Learn (flashcards), Map quiz, Nature, Play. Map quiz (`src/quiz/`: blank continent, click a country, answer box linked by a line; easy = country name, hard = + capital; flag tip; quiz progress in its own localStorage key `country-capitals:quiz:v1`). Correctly named countries get a name label on the map (`WorldMap` prop `labelIds`, shown only when the country is wide enough on screen) and the box shows `CountryFacts`.
- Nature tab (`src/nature/`, README section 7): rivers / waters / mountains per continent, Explore list + typing Quiz. List with texts in `data/nature.ts`; shapes generated by `npm run data:nature` into `data/nature-geo.json` (Natural Earth, cached in scripts/.cache/ne). Lazy-loaded chunk. Drawn via `WorldMap` props `overlay` (paths from `geoPathD`), `targetLonLat` (ring) and `fitBox` (widens the continent view). Key figures + countries in `data/nature-facts.ts` (`NatureFactsView`). Quiz: tap a shape (`.nat-hit` paths) to answer it; named = green + name via `WorldMap` prop `freeLabels`; rounds in `country-capitals:nature:rounds:v1`, known/missed in `country-capitals:nature:v1`. Colors `--n-water`, `--n-mountain` in index.css.
- Africa regions: `Area` = continent or region (`North/West/East/Southern Africa`, `REGION_IDS` in `src/data/countries.ts`, test checks all 54 assigned). Store scope, StudyView, WorldMap zoom (`VIEW_BOX`), map quiz select (optgroup) all take an `Area`. Home: region picker appears when Africa is selected.
- "Practice all N": a session through every country of a continent regardless of what is due (`StudyView` with `practice`); does NOT touch the SRS schedule.
- Country-name answers use `checkCountryName` (en/de name + `nameAliases` from the dataset's official name/altSpellings + `overrides.json` → `nameAliases`).
- The service worker is registered in `main.tsx` with auto-reload, so a rebuilt version shows up immediately.
- Learn direction switch (side panel): Country → Capital or Capital → Country. Separate decks: store methods take `dir` (default `'capital'`), reverse cards saved as `r:<id>` (`cardKey` in store.ts). UI direction in `progress.ts` (`useDirection`/`setDirection`, localStorage `country-capitals:direction`); map colors, home numbers and Stats follow it, the cloud leaderboard always uses the capital deck.
- After a wrong answer the learner must re-type the correct capital (exact match) before the next card; the card counts as Again.
- Launcher always kills an old server on port 4173 and starts fresh after rebuilding.
- Gotchas: tsconfig has `erasableSyntaxOnly` (no constructor parameter properties); `sed -i` fails on this Mac in some commands, use python for edits; remember to kill stray `vite preview` processes (port 4173) after testing.
- Accounts (optional): Firebase free Spark plan, config in `src/cloud/config.ts` (null = off, no login, app as before). `cloud.ts` = auth state (`useAccount`), sync (local store stays main copy; debounced merge via `progress/merge.ts` + upload), leaderboard; `firebase.ts` is lazy-loaded. Firestore: `players/{uid}` public card, `progress/{uid}` private JSON; rules in `firestore.rules`. Friends tab (`pages/Friends.tsx`) only shows when configured. Sign-out wipes local progress; Reset/Import push with overwrite. Setup steps: README section 5.
- Play tab (`src/games/`, README section 6): 4 modes (capital, flag, reverse, pin), 10 questions x 15 s, points 100 + speed bonus; pin = distance points. Async duels in Firestore `matches/{id}` (same questions for everybody, invite friends or share `?duel=ID` link, `useMatches()` live list in cloud.ts, nav badge when it's your turn). Quiz duel (`src/games/quizduel.ts` logic + tests, `QuizDuelView.tsx`, `QuizDuelPlay.tsx`): 1v1, 6 rounds x 3 multiple-choice questions, categories capital / country (flag) / river / mountains / water, players take turns choosing; Firestore `quizduels/{id}` with `turn`, `useQuizDuels()` in cloud.ts, nature questions show `nature/NatureShape` (lazy, shares `nature/geo.ts` with the Nature tab). Rule changes must be re-pasted into the Firebase console by the owner.
- Browser testing: headless Chrome via a small CDP script works (`/Applications/Google Chrome.app`, Node has global WebSocket); override `window.confirm` or it blocks.
- Deployed: repo https://github.com/paulannosenger-ux/country-capitals (public), live at https://paulannosenger-ux.github.io/country-capitals/ via the GitHub Action on every push to main. Commits use the GitHub noreply email (never the owner's gmail). Publishing/pushing to the public repo is blocked for Claude by the auto-mode classifier: give the owner the command to run in the VS Code terminal.
